# Планы

Здесь лежат планы работ: брифы, статусы и задачи. Их пишут и читают чаты с агентом по скиллу
`team-task-workflow`: файл вставляется в новый чат целиком, и чат делает один кусок работы.

- У каждого разработчика своя папка `docs/plans/<логин>/`: в ней планы, которые он написал.
  Продолжать чужую работу нужно в папке автора, не перенося её.
- План фичи коммитится в ветку этой фичи вместе с кодом. Чтобы подхватить работу, достаточно
  взять ветку и открыть `STATUS.md` фичи.
- После закрытия фичи файлы задач удаляются; остаются `BRIEF.md` и `STATUS.md` с итогом. Удалённое
  достаётся из истории по хешу из строки «Архив».
- Планы читает вся команда: без секретов, токенов и данных клиентов.
